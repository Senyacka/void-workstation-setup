void-workstation - перенос настроек рабочего стола на чистый Void Linux
========================================================================

Что нужно ДО запуска:
  1. Установленный Void Linux (void-installer с live-ISO).
  2. Пользователь, добавленный в группу wheel; sudo без пароля.
  3. Интернет на целевой машине (кабель: dhcpcd, Wi-Fi: wpa_supplicant).
  4. Не меньше 8 ГБ свободного места на /.

Как запустить:

  sudo mkdir -p /mnt/usb
  sudo mount /dev/sdX1 /mnt/usb          # sdX1 - раздел флешки, см. lsblk
  sh /mnt/usb/void-workstation/install.sh

Дальше всё делается в меню. Клавиши:
  стрелки, PgUp/PgDn, Home/End - листать
  Пробел                       - включить или выключить пункт (на строке группы - всю группу)
  Enter                        - подтвердить / дальше
  Esc                          - назад

Проверить файлы перед запуском:
  cd /mnt/usb/void-workstation && sha256sum -c checksums.sha256

После установки перезагрузитесь. Проверка состояния системы:
  healthcheck

Установщик ничего не удаляет: каждый изменённый файл сохраняется рядом
с оригиналом как <имя>.pre-setup.<дата>.
